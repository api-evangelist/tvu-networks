TVU Networks is a live video transmission and cloud production company founded in 2005 and headquartered in Mountain View, California. Its IP-based ecosystem covers acquisition (TVU One and TVU Anywhere bonded-cellular transmitters), cloud routing and distribution (TVU MediaHub), cloud production (TVU Producer, TVU Partyline, TVU Remote Commentator), FAST and linear playout (TVU Channel), and AI-assisted media management and search (TVU MediaMind, TVU Search). TVU publishes a public HTTP API across those products — 352 operations spanning MediaHub routing, Search and metadata, Producer control, Grid device transmission, Partyline, Channel playout, SCTE-35 ad insertion and a MOS newsroom gateway — documented on its own Apifox-hosted API documentation site, with Bearer AppSecret, SID session and AccessKey-signature authentication.

**Areas:** Company · Media · Video · Broadcast · Live Streaming · Video Transmission · Cloud Production · Media Supply Chain · Playout · FAST · Remote Production · Metadata

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for TVU Networks: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
